# Market Range Signal Desk

Market Range Lab 的獨立新版介面原型；不會修改或取代正式的
`market-range-lab`。

目前選定 **A · Signal Desk** 作為主要方向。B · Range Canvas 與
C · Night Ledger 保留為設計比較資料。

## Run

```powershell
npm install
npm run dev
```

開啟終端機顯示的網址。預設為 Signal Desk；也可用
`?variant=signal`、`?variant=canvas`、`?variant=night` 直接切換。

## Scope

- 使用合成示意數據
- 沒有後端、CSV 解析、即時報價或正式模型
- 互動只用來驗證資訊架構、元件組合與視覺語言
