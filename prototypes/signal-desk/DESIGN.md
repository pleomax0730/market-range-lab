# Design System — Range Instruments

## Design premise

介面是一套「風險量測儀器」，不是一般 SaaS 卡片牆。每個模組像可替換的量測頭：價格帶、事件證據、回復路徑與模型狀態共享同一資料語法，但三個原型方向使用不同的空間編排。

## Shared rules

- 數字使用 tabular figures；只有真正的市場數據或計量值使用等寬字。
- 主要狀態以字詞、圖形與顏色共同表達。
- 控制項最小高度 40px，focus ring 明確，hover 不改變版面尺寸。
- 大數字只用於目前價、選定履約價與核心機率；事件數與區間是第二層。
- 動態只解釋狀態變化：數字切換、面板展開、期限游標移動。
- 所有原型數據均顯示「示意資料」。

## Variant A — Signal Desk

明亮工作台。墨黑文字、冷白底、酸橙作選定狀態、氧化藍與琥珀表達下檔風險。左側是控制脊柱，中間以連續價格軌道取代卡片牆，右側是模型敘事。適合高頻操作。

## Variant B — Range Canvas

紙上分析畫布。暖灰底、深靛藍、番紅花橘與薄荷綠；以大面積區間帶和批註呈現「從目前價走到候選價」的故事。適合慢速比較與教學。

## Variant C — Night Ledger

夜間研究帳本。深李色而非純黑，骨白文字、粉橘與青灰訊號；用垂直事件帳本與可展開抽屜組織資料。適合專注檢查與長時間閱讀。

## Component lineage

- shadcn/ui：可組合、可擁有原始碼的控制骨架。
- Beautiful UI：模型解釋列、任務狀態與推薦卡的資訊節奏。
- beUI：可變形搜尋／選擇器、展開式工具列與檔案匯入語彙。
- Rare UI：步驟播放器與側欄展開的空間感，僅吸收互動原則。
- Transitions.dev：數字 pop、文字狀態交換、panel reveal；只使用自行實作的基礎轉場。
